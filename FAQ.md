# FAQ

## Is this public repository the full source code?

No. This repository is a public showcase. The paid source package is delivered separately after purchase.

## What is included in the paid package?

The paid package includes the application source code, local development stack, setup documentation, AI setup guide, deployment notes, demo script, known limitations, rebranding notes, and buyer handoff documentation.

## Is the product production-ready?

It is an MVP codebase, not a fully managed production SaaS. It is intended to be easy to run locally, evaluate, customize, and extend. Production launch requires buyer-side validation, real secrets, hosting, monitoring, legal policies, payment setup if needed, and operational hardening.

## Can I rebrand it?

Yes. The package is designed to be rebranded. Buyers can change the app name, logo, theme, landing copy, metadata, email sender, and pricing labels if they add billing.

## Does it include AI provider keys?

No. Buyers must provide their own API keys. The app includes saved provider setup and provider testing flows, but no seller secrets are included.

## Which AI providers are supported?

The private package includes provider setup for common AI SDK providers such as OpenAI, Anthropic, Gemini, OpenRouter, Vercel AI Gateway, Ollama, and OpenAI-compatible providers. Exact behavior should be tested with the buyer's chosen model and provider.

## Does it include payment or subscription billing?

Payment and billing are not included by default unless separately added. The codebase is positioned as an MVP foundation that can be extended with Stripe, Lemon Squeezy, Paddle, or another billing provider.

## Can I resell the source code?

No. The intended license allows one commercial product, but not resale, redistribution, sublicensing, publishing, or selling the source as a codebase/template.

## Can the seller keep using or selling it?

Yes. The intended license is non-exclusive. The seller can continue using, modifying, and selling related versions.

## Is there support after purchase?

Support depends on the sale agreement. By default, the purchase includes source code and docs. Setup calls, deployment help, custom branding, production hardening, and feature work should be priced separately.

## What should I check before buying?

Review the screenshots, demo video, limitations, setup preview, tech stack, license summary, and buyer handoff preview. Ask for clarification if a specific production requirement matters to your business.
