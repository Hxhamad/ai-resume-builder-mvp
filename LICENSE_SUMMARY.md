# License Summary

This file summarizes the intended non-exclusive commercial license for buyers. It is not formal legal advice. Have a lawyer review the final license terms before selling at scale.

## Intended Buyer Rights

The buyer may:

- Use the purchased source code for one commercial product.
- Modify, rebrand, and extend the codebase.
- Deploy the product for their own users or clients.
- Create private internal forks for their team.
- Add their own hosting, domain, AI keys, storage, email, and payment accounts.

## Restrictions

The buyer may not:

- Resell the source code as a template, boilerplate, starter kit, or codebase.
- Redistribute, sublicense, upload, leak, or publish the private source package.
- Claim exclusive ownership of the original codebase.
- Claim the seller has stopped using, modifying, or selling related versions.
- Use the seller's private API keys, accounts, domains, customer data, or infrastructure.

## Seller Rights

The seller keeps the right to:

- Continue using the codebase for their own SaaS or startup.
- Modify and improve the codebase.
- Sell non-exclusive licenses to other buyers.
- Reuse ideas, architecture, components, documentation, and future improvements.

## Buyer Responsibilities

The buyer is responsible for:

- Generating production secrets.
- Providing AI provider credentials.
- Providing hosting, domain, storage, email, payment, and analytics accounts.
- Validating production deployment.
- Adding legal policies, privacy terms, compliance checks, backups, monitoring, and support processes.

This public repository is a showcase and proof page only. It does not grant access to the private source code.
