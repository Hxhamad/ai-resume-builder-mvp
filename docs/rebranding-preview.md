# Rebranding Preview

The paid package uses ResumeMe as a demo brand, but buyers can rebrand it.

## Common Rebranding Areas

- App name.
- Logo and app icon.
- Favicon and PWA icons.
- Theme colors.
- Homepage copy.
- Metadata and OpenGraph text.
- Email sender name if email is configured.
- Public sharing copy.
- Product screenshots.
- Pricing labels if billing is added.

## Practical Advice

Keep the first buyer rebrand conservative:

- Change the name and logo.
- Update homepage and auth copy.
- Replace screenshots.
- Use a small, credible feature set.
- Do not promise production readiness until the deployment has been validated.

## Namespace Note

The private source package may retain legacy internal package names. That is acceptable for an MVP handoff. A full namespace rename can be done later, but it is not necessary for a buyer demo or first launch.
