# Features Preview

The paid codebase is positioned as an AI resume-builder MVP foundation.

## Customer-Facing Product

- Landing page with premium ResumeMe positioning.
- Auth pages for local email/password login and registration.
- Dashboard shell with sidebar navigation.
- Resume cards, empty states, loading states, and error states.
- Create resume and import resume flows.
- Builder header, dock, sidebars, and resume preview.
- Settings and integrations screens.

## Resume Builder

- Basics editing.
- Summary editing.
- Experience editing.
- Education editing.
- Skills editing.
- Optional and custom sections.
- Template, typography, design, and layout controls.
- Live preview.
- Refresh/reopen persistence flow.

## Export And Sharing

- JSON export.
- DOCX export.
- PDF export.
- Public sharing controls.
- Privacy-oriented copy for sharing and access states.

## AI Features

- Buyer-owned AI provider setup.
- Provider test flow.
- AI resume analysis.
- AI import assistance where provider/model support allows.
- Agent thread that can propose structured resume edits.
